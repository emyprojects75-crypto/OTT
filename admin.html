Channels

Import from JSON
A JSON array of channel objects: channelId, name, language, category, streamUrl required. Optional: logoUrl, epgId, isLive, isPremium, sortOrder.
Import from M3U / M3U8 playlist
Standard IPTV playlist format (#EXTM3U / #EXTINF lines) — different from a single stream URL. Upload a .m3u/.m3u8 file, or paste a link to one hosted online (e.g. Firebase Storage, your own server).
Import from CSV or Excel (.xlsx)
Required columns: channelId, name, language, category, streamUrl. Optional: logoUrl, isLive, isPremium, sortOrder.

Movies & Shows

Import from M3U / M3U8 playlist
Same playlist format as Channels — each #EXTINF entry becomes one movie/show. group-title becomes category, tvg-logo becomes the poster.
Import from JSON
A JSON array of movie objects: movieId, title, language, category, streamUrl required. Optional: posterUrl, isPremium, sortOrder.
